## Completion Call Parity — Code Reference Summary

The Ethereum and Robinhood completion APIs are intentionally mirrors of each other, differing only in:

| Dimension | `/api/evm/complete` | `/api/lifi/complete` |
|---|---|---|
| Quote proof fields verified | `{ chainId:1, wallet, sellToken, buyToken, sellAmount, buyAmount }` → checks `tx.to / tx.input / tx.value` against `trustedQuote.to/data/value` | `{ provider:'lifi', fromChain,toChain, wallet, fromToken/toToken(lower), fromAmount,toAmount }` → checks `tx.to/input/value` against `proof.transactionTo/transactionData/transactionValue` |
| RPC source | `ETHEREUM_RPC_URL` (single provider) via [ethereum.mjs ethereumRpc()](file:///C:/Users/user/Desktop/Assignment/Ronin%202/Ronin-repo/api/_lib/ethereum.mjs) | `lifiRpc(fromChain,…)` router in [lifi.mjs](file:///C:/Users/user/Desktop/Assignment/Ronin%202/Ronin-repo/api/_lib/lifi.mjs) which picks per-chain RPC URL from config |
| Duplicate check | `getEthereumSwapByHash(txHash)` — `WHERE chain_id=1 AND transaction_hash=?` | `getLifiSwapByHash(txHash)` — `WHERE provider='lifi' AND transaction_hash=?` |
| Token whitelist check | Implicitly via 0x quote HMAC proof binding + sell/buy token address validation | Explicit `Promise.all([ isApprovedLifiToken(from), isApprovedLifiToken(to) ])` before persistence |
| Persist function | `persistEthereumSwap()` → provider='0x', chain_id=1, NO quote_id column | `persistLifiSwap()` → provider='lifi', chain_id=fromChain, quote_id=quoteId column SET |
| calculateSamuraiPoints chain_id | Hard-coded `chain_id: 1` in input payload | `chain_id: Number(fromChain)` (allows future cross-chain points on different source chains) |
| Receipt status check | `receipt.status === '0x1'` only | Broader `receiptSucceeded()`: `'0x1' | '0x01' | 1 | '1' | true` (matches both hex & numeric) |
